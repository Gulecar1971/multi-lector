# MultiLector

Lector y conversor de archivos para Android. Gratis, sin límites, sin publicidad y sin internet.

**Abre:** PDF, Word (.docx y .doc viejo), Excel (.xlsx y .xls viejo), PowerPoint (.pptx y .ppt), LibreOffice (.odt .ods .odp),
ePub, RTF, TXT, CSV, Markdown, JSON, HTML, XML, fotos (JPG, PNG, WEBP, HEIC, GIF, BMP, SVG), ZIP, videos y audios.

**Convierte a PDF:** todo lo anterior (menos ZIP, videos y audios), uno por uno o todo junto en un PDF.

**Fotos a PDF exactas:** los JPG se guardan dentro del PDF byte a byte; los demás formatos sin pérdida y con el original adjunto.
Al sacarlas con "Sacar las fotos de un PDF" salen idénticas a las originales.

**Herramientas:** sacar fotos de cualquier PDF, pasar páginas a fotos, unir PDFs y fotos, achicar PDFs,
escanear con la cámara, achicar/recortar/cambiar formato de fotos (WhatsApp, Catálogo, Mercado Libre, Instagram, carnet, trámites…).

Desde otras apps: "Compartir → MultiLector" o "Abrir con → MultiLector".

La app se compila sola en GitHub Actions y se publica en "Releases" como `MultiLector.apk`.
